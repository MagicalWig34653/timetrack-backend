# Dokumentation

Diese Seiten werden beim Bauen der Website aus den Dokumenten im Repository übernommen. Die Quelle bleibt das Repository; hier wird nichts doppelt gepflegt.

## Wo anfangen?

::: tip Selbst betreiben?
Starte mit dem **[Überblick der Installation](/docs/installation)**: Er hilft bei der Wahl zwischen Docker Compose (ein Server) und Docker Swarm (Cluster). Danach folgt die **[Ersteinrichtung](/docs/installation/ersteinrichtung)**.
:::

| Ich möchte … | Lies |
| --- | --- |
| Timetrack installieren und die Wahl treffen | [Installation: Überblick](/docs/installation) |
| auf **einem** Server betreiben | [Docker Compose](/docs/installation/compose) |
| im Cluster betreiben | [Docker Swarm](/docs/installation/swarm) |
| eine eigene MariaDB vorbereiten | [Eigene MariaDB](/docs/installation/mariadb) |
| HTTPS davorsetzen | [Reverse Proxy und TLS](/docs/installation/proxy) |
| den ersten Admin anlegen und einrichten | [Ersteinrichtung](/docs/installation/ersteinrichtung) |
| aktualisieren, sichern, Probleme lösen | [Aktualisieren](/docs/update), [Sichern](/docs/installation/backup), [Probleme](/docs/installation/probleme) |
| alle Einstellungen nachschlagen | [Konfiguration](/docs/installation/konfiguration) |
| das Image selbst bauen | [Image selbst bauen](/docs/image-bauen) |
| einen KI-Assistenten anbinden | [MCP-Anbindung](/docs/mcp) |
| die API ansprechen | [API-Referenz](/api/) |
| verstehen, was Timetrack kann und was offen ist | [Konzept](/docs/konzept) |
| wissen, wie es technisch aufgebaut ist | [Architektur](/docs/architektur) und [Architekturentscheidungen](/adr/) |
| es für die Entwicklung lokal starten | [Entwicklung einrichten](/docs/einrichtung) |
| verstehen, wie gebaut und veröffentlicht wird | [CI und Pages](/docs/ci) |
| die Gestaltung nachvollziehen | [Designsprache](/docs/design) |

Der **Umsetzungsstand** steht in [Umsetzung](/docs/umsetzung). Die Dokumentationslandkarte des Repositories, die zusätzlich interne Arbeitsdokumente verzeichnet, liegt unter [`docs/README.md`](https://github.com/MagicalWig34653/timetrack-backend/blob/main/docs/README.md).
