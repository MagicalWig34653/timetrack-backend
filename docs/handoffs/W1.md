# Handoff W1 (Backend): Abgang beendet fremde Timer, Auslöse-Links

Stand: 22.10.2026. Branch `worktree-agent-a96dfb882f965b00e` (auf main 1e2cca7, Vertrag 0.25.0), nicht gepusht, nicht gemergt. Vertrag **v0.26.0**. Entscheidungen: ADR-0027.

## Was gebaut ist

**A: Abgang.** `AutomationService.process`: `departure` ohne offenen Besuch (keine Ankunft) beendet einen laufenden Abschnitt beliebiger Quelle (`stopRunning`). `direct`: Ende = `occurredAt`, Ergebnis `booked`; `suggest`: Ende-Vorschlag (`suggested`, kein zweiter, solange einer offen ist); `off`/archiviert: `recorded` (unverändert). Abschnitt mit anderem Ort: `ignored`. Vorbeifahrt unverändert `ignored`. Kein laufender Timer und keine Ankunft: `ignored` (vorher `needs_review`). MCP hat kein Automations-Tool, REST ist der einzige Weg.

**B: Auslöse-Links.** `Sources/TimetrackKit/TriggerLinks.swift`: Tabelle `trigger_links` (Hash, Bezeichnung, Aktionen, Ort, Art, Ablauf, Widerruf, zuletzt benutzt), Verwaltung, Ausführung, Route `GET /t/:token/:action`, Log-Schwärzung (`TriggerTokenScrubber`, im `TimestampedLogHandler`). Anpassungen: `PWAStaticMiddleware` (`/t` nie SPA-Hülle), `APIErrorMiddleware` (`no-store` auch für `/t/`), Modulzuordnung (`me/trigger-links` → `automation`), Kontoexport (`trigger-links.json`, ohne Token), Kontosperre/-löschung. Betreiberhinweis zu Proxy-Zugriffsprotokollen in `docs/installation/proxy.md`.

## Vertrag, den die PWA umsetzen muss (Verwaltungsansicht, z. B. neben Gerätetokens/Verbindungen, nur sichtbar bei aktivem Modul `automation`)

- `GET /api/v1/me/trigger-links` → `TriggerLink[]` (nur aktive; **nie** `token`/`path`): `id`, `label`, `actions` (`start|stop|toggle`), `placeId|null`, `kind` (`work|travel|school`), `createdAt`, `expiresAt|null`, `lastUsedAt|null`, `lastAction|null`.
- `POST /api/v1/me/trigger-links` (Sitzung + CSRF), Body `{label (≤80, nicht leer), actions (≥1), placeId?, kind?, expiresInDays? (1–730)}` → 201 mit `TriggerLink` plus `token` und `path` (`/t/<token>`). **Einmalig anzeigen und kopierbar machen** (vollständige URL = `location.origin + path`, ggf. je Aktion `…/start`, `…/stop`, `…/toggle` zeigen); danach nicht rekonstruierbar, Hinweis „jetzt kopieren“. Fehler: 400 (ungültig), 404 (Ort unbekannt), 409 `too_many_trigger_links` (20 aktive).
- `DELETE /api/v1/me/trigger-links/{id}` → 204 (idempotent), fremde Id 404; Link antwortet danach sofort 404.
- Anzeige: Bezeichnung, Aktionen, Ort, „zuletzt benutzt“ (`lastUsedAt` + `lastAction`), Ablauf. Sicherheitstext (deutsch): URL ist wie ein Passwort; nicht teilen; ein Link je Zweck; bei Verdacht sofort widerrufen; Link landet in Browserverlauf/Protokollen des aufrufenden Geräts; wer einen Header setzen kann, nimmt das Gerätetoken.
- Aufruf-Semantik zum Erklären (Hilfetext): `GET /t/<token>/start|stop|toggle`, optional `?at=<ISO 8601>` (höchstens 2 h zurück), `?place=<Ort-ID>` (nur bei Link ohne Ortsbindung), `?format=text`. Antworten: `started`, `stopped`, `suggested`, `already_running`, `already_stopped`, `ignored`, `needs_review`; 404 für alles Unbekannte; 429 bei Überlast.
- Die PWA ruft `/t/…` nie selbst auf; der Service Worker darf `/t/` nicht abfangen oder cachen (Navigation-Fallback ausnehmen), sonst wird die SPA-Hülle statt der Antwort geliefert.

## Offene Punkte

1. Aufräumjob entfernt abgelaufene/widerrufene Links nicht (kein Schritt in `MaintenanceService`; Datenmenge klein, Höchstzahl gilt nur für aktive Links).
2. Ratenbegrenzung je Client nutzt `clientRateLimitKey` (ohne `TRUSTED_PROXY_*` hinter einem Proxy teilen sich alle Clients einen Zähler; dann 30 Fehlversuche je 5 Minuten für alle).
3. Zugriffsprotokolle des Reverse Proxys sind nicht beeinflussbar (nur Dokumentation).
4. Ein Start nach einem Stopp kann nicht von einer verspäteten Wiederholung eines früheren Starts unterschieden werden (GET ohne Ereignis-ID); `toggle` hat daher den 10-s-Schutz, `start`/`stop` sind nur bezüglich des Zustands idempotent.
5. Die Start-Quelle der Abschnitte aus Links ist `automation` (Folgetag-Prüfung „fehlendes Ende“ greift); die PWA zeigt sie wie andere Automatik-Abschnitte.
6. Nicht auf Echtgeräten/mit echtem Proxy erprobt.
