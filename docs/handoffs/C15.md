`learning_fields` (unique account_id+name_key), `report_entries` (index account_id+date), `report_week_status` (unique account_id+iso_year+iso_week, CHECK status), `report_sources` (index account_id+iso_year+iso_week). ## Decisions (beyond ADR/contract)
- Case-insensitive unique name via a stored lower-cased `name_key` (works identically on SQLite and MariaDB); names are trimmed; 409 `learning_field_exists`.
- Deleting a learning field clears `learning_field_id` of its entries (snapshot name stays); renaming never touches entries. Updating an entry with `learningFieldId` re-reads the current name.
- `learningField` is optional in the request when `learningFieldId` is given (the contract lists it as required; this is a superset).
- Missing or non-numeric If-Match gives 412 `stale_version` (same as the other modules). Quoted values are accepted.
- ISO weeks are computed on `LocalDate` (Jan 4 anchor, a week belongs to the year of its Thursday) instead of `Calendar`, to be independent of platform calendar behaviour; a test cross-checks every day 2015-2040 against `Calendar` (Monday, minimumDays 4). Valid years 1900-2200.
- `trackedWorkSeconds` = sum of `evaluatedWorkSeconds` of the 7 days from the existing day evaluation; a day whose evaluation fails counts 0.
- Text format: header, blank line, per non-empty day `<Wochentag>, <dd.MM.yyyy>` and lines `<Lernfeld> | <h:mm> h | <Notiz>`, blank line between days, `Summe: <h:mm> h`, trailing newline. Empty note: the last `| ` part is omitted. Line breaks (LF, CR, CRLF, NEL, U+2028/2029) in notes become ` / `, empty lines dropped; the learning field name is single-lined the same way. Nothing is escaped or prefixed (a leading `=` stays as typed). Minutes are truncated.
- Sources: a note that is empty after trimming counts as absent; `date` must lie inside the given week; deleting a source keeps the file; a deleted file leaves the source without `file`. Only `stored` files of the caller are accepted.
- Entries created via the API always have `draft=false` (the field exists for the later AI drafts).
- No sharing: report data is not part of any share view or share scope (asserted in tests). Writes by recovery sessions are blocked (403).
